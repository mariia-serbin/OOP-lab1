Detailed Description

List data structures module.

Contains abstract base class for lists (BaseList) and implementations based on arrays (ArrayList), singly linked lists (LinkedList), doubly linked lists (DoublyLinkedList), and Python built-in lists (LibraryList). Provides all basic operations including addition, removal, retrieval, setting, swapping, and computation of maximum and minimum values. Handles exceptions for invalid indices and empty structures.
