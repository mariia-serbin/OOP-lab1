Detailed Description

Merge Sort algorithm.

Merge Sort is a divide-and-conquer, comparison-based sorting algorithm. The list is recursively divided into two halves until each sublist contains a single element. Then, the sublists are merged back together in a sorted manner. Merge Sort is stable and works efficiently for large datasets with guaranteed O(n log n) time complexity. More info: https://www.geeksforgeeks.org/dsa/merge-sort/
