Detailed Description

Quick Sort algorithm.

Quick Sort is a divide-and-conquer sorting algorithm. It works by selecting a "pivot" element from the list and partitioning the other elements into two sublists: those less than the pivot and those greater than the pivot. The sublists are then recursively sorted. This method is efficient for large datasets and has an average time complexity of O(n log n). Worst-case time complexity is O(n^2), which can be mitigated by choosing a good pivot strategy. More info: https://www.geeksforgeeks.org/dsa/quick-sort-algorithm/
